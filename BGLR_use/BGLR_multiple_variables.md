# BGLR Documentation: Implementing Multiple Variables

---

## 1. Overview and Best Practices

The `BGLR` (Bayesian Generalized Linear Regression) package handles multiple predictors (covariates) differently than standard formula-based packages like `lme4` or `sommer`. Instead of stringing variables together in a formula (e.g., `y ~ x1 + x2 + x3`), BGLR requires you to pre-compile all fixed covariates into a single design matrix.

This approach ensures computational efficiency during the Gibbs sampling process, especially when integrating low-dimensional fixed effects with high-dimensional genomic data ($p \gg n$).

### The Golden Rule: Drop the Intercept

By default, the `BGLR()` function automatically calculates and fits a global intercept ($\mu$). When generating your fixed effect matrix using base R's `model.matrix()`, it will also generate an intercept column. **You must remove the matrix's intercept column before passing it to BGLR.** Failure to do so will result in collinearity errors as the model attempts to fit two identical intercepts.

```R
# CORRECT: Bundling variables and dropping the first column (intercept)
X_fixed <- model.matrix(~ Age + Treatment + Temperature, data = df)[, -1, drop = FALSE]

```

## 2. Standard Mixed Models (No Kinship Matrix)

When fitting standard hierarchical models with multiple predictors and random grouping factors (comparable to `lme4`), use the `FIXED` model for covariates and the `BRR` (Bayesian Ridge Regression) model for random intercepts.

### Data Preparation and ETA Construction

```R
# 1. Bundle fixed covariates (continuous and categorical)
X_covariates <- model.matrix(~ Age + Treatment, data = dat)[, -1, drop = FALSE]

# 2. Create incidence matrix for the random grouping factor (e.g., Herd)
# Exclude intercept (- 1) so it acts purely as a random effect matrix
Z_group <- model.matrix(~ Herd - 1, data = dat)

# 3. Stack components in the ETA list
ETA_standard <- list(
  list(X = X_covariates, model = "FIXED"),
  list(X = Z_group,      model = "BRR") 
)

# 4. Fit the model
fit <- BGLR(y = dat$y, ETA = ETA_standard, nIter = 5000, burnIn = 1000)

```

**Extracting Estimates:**

* Global Intercept: `fit$mu`
* Fixed Covariate Effects: `fit$ETA[[1]]$b`
* Random Group Variance: `fit$ETA[[2]]$varB`

## 3. Animal Models (With Kinship Matrix)

When modeling multi-variable fixed effects alongside a Numerator Relationship Matrix ($A$) or Genomic Relationship Matrix ($G$), BGLR utilizes the `RKHS` (Reproducing Kernel Hilbert Spaces) framework. This is the Bayesian equivalent to `sommer`'s `mmer()` function.

### Data Preparation and ETA Construction

```R
# 1. Bundle fixed covariates
X_covariates <- model.matrix(~ Age + Diet, data = df_animals)[, -1, drop = FALSE]

# 2. Stack the fixed covariates and the relationship matrix (A_mat)
ETA_animal <- list(
  list(X = X_covariates, model = "FIXED"),
  list(K = A_mat,        model = "RKHS") 
)

# 3. Fit the model
fit_animal <- BGLR(y = df_animals$Phenotype, ETA = ETA_animal, nIter = 5000, burnIn = 1000)

```

**Extracting Estimates:**

* Additive Genetic Variance: `fit_animal$ETA[[2]]$varU`

## 4. Integrating Environmental and Genomic Data

One of BGLR's most powerful applications is combining multi-variable environmental data (e.g., Temperature, Photoperiod) with raw genetic marker data. By stacking a `FIXED` environmental matrix with a `BayesB` genomic matrix, the model accurately accounts for environmental slopes while applying a spike-and-slab prior to select major quantitative trait loci (QTLs).

### Data Preparation and ETA Construction

*Note: Ensure the marker matrix is expanded so the number of rows perfectly matches the number of observations in the phenotypic dataset.*

```R
# 1. Bundle environmental fixed effects
X_env <- model.matrix(~ Temp_C + Photoperiod_hr, data = df_trials)[, -1, drop = FALSE]

# 2. Stack environmental data with raw marker data
# We use BayesB to isolate major genes (e.g., flowering pathway genes)
ETA_genomic_env <- list(
  list(X = X_env,              model = "FIXED"),
  list(X = X_markers_expanded, model = "BayesB", probIn = 0.05) 
)

# 3. Fit the model
fit_genomic <- BGLR(y = df_trials$Trait, ETA = ETA_genomic_env, nIter = 5000, burnIn = 1000)

```

## 5. Troubleshooting Guide

| Error/Issue | Likely Cause | Solution |
| --- | --- | --- |
| **Collinearity / Singular Matrix** | The global intercept `mu` is clashing with the intercept generated by `model.matrix()`. | Ensure you subset the matrix using `[, -1, drop = FALSE]` to remove the first column. |
| **Dimension Mismatch** | The number of rows in the covariate matrix ($X$) does not equal the length of the response vector ($y$). | Ensure missing data (NAs) in the raw dataframe were handled uniformly before building matrices and the response vector. |
| **Poor Shrinkage on Covariates** | The covariates were accidentally assigned a Bayesian shrinkage prior (like `BRR` or `BayesA`) instead of `FIXED`. | Double-check the ETA list. Covariates that should not be shrunk toward zero must be explicitly assigned `model = "FIXED"`. |
